# Moon Journey 仕掛け・ステージ・アイテム案 v0.1

前提：操作は「押すと FAST／離すと SLOW」の1つだけ。1回のホップは常に 0.78 秒で、速さによって着地点が変わる。予測リングで着地点が見える。
どの案も、この「着地点を速さで選ぶ」という動詞を深めるものにする。

## 1. 足場とギミック

| 案 | 内容 | 新しく生まれる判断 | 実装の重さ |
|---|---|---|---|
| **流星橋**（月光橋の逆） | FAST で着地したときだけ固い。SLOW では透ける | 月光橋と並べると、着地ごとに「押したまま／離して」を切り替える必要が出る | 小（`collisionView` に種類を1つ足す） |
| **満ち欠け足場** | 足場が一定周期（0.78 秒の倍数）で満ちたり欠けたりする。満ちている間だけ乗れる | 距離に加えて「何回目のホップで降りるか」を選ぶ | 中 |
| **風の帯** | 空中の帯を通ると前へ押される／押し戻される。予測リングはその分も計算する | 「リングを信じる」ことを教え、速さの使い方を変える | 中 |
| **ばね雲** | 着地すると次の1回が高く遠いホップになる（周期は変えない） | 遠い島へのショートカット。ただし行き過ぎる危険がある | 中 |
| **星の門** | 空中の門。FAST で通り抜けたときだけ開き、先の隠し足場が現れる | 寄り道ルートの入口 | 中 |

## 2. アイテム（団子を「意味のあるもの」に）

いまの団子は地球見祭に届ける贈り物で、数えるだけになっている。次の候補がある。
- **お守り団子**：持っていると、1回だけ落ちる前に月印から再開できる。危険な近道に挑む理由になる。
- **三色団子セット**：ステージごとに桃・白・緑の3個。全部そろえると、地球見祭の灯りが増えたり、エンディングが変わったりする。
- **星くず**：空中の筋に沿って並ぶ小さな光。FAST で弧を描くと集まる。スコアと、衣装の解放に使う。
- **月のしずく**：拾うと次の1回だけ、FAST と SLOW の両方の着地点が同時に見える。初心者向けの救済。

## 3. ステージ構成（章立て）

1. **月の庭**（既存）：長押しの練習。
2. **夜風の間**（既存）：距離の調整。
3. **月光橋**（既存）：離す練習。
4. **ふたつの月道**（既存）：選択。
5. **流星の海**：流星橋と月光橋が交互に並ぶ。押し離しのリズムを覚える章。
6. **満ち欠けの谷**：満ち欠け足場と風の帯。
7. **影の街**：日食の影。リングを信じる章。
8. **地球見の夜**（既存のフィナーレ）：集めた団子の数でお祭りが変わる。

各章は3〜5ステージ。最初の1面で仕掛けを単独で見せ、続く面で既存の仕掛けと組み合わせる。

## 4. 長く遊べる仕組み

- **ステージごとの3つの月**：クリア、FULL MOON（月印を使わない）、団子。月道バーにそのまま並べられる。
- **ミッション**：「FAST 合計2秒以内」「ホップ12回以内」など。どれも既存の記録だけで判定できる。
- **タイムアタック／最少ホップ**：ルートの最適化を楽しむ遊び方。
- **ゴースト**：前回の自分の跳び方を半透明で表示する。
- **今日の月道**：日付をシードにして生成し、既存のソルバーでクリアできるか確認してから出す。毎日1本。
- **エンドレス**：生成したコースを延々と跳ぶ。距離が伸びるほど仕掛けが増える。

## 5. おすすめの順番

1. **流星橋＋流星の海の章**（v0.5 で実装：Stage 006）：物理を変えずに、足場の種類を1つ増やすだけで済む。月光橋との対で、遊びの幅がいちばん広がる。
2. **団子をお守りにする**：「団子を取るとどうなるか」に、遊びの上の答えが出る。
3. **3つの月とミッション**：既存の5ステージだけで、繰り返し遊ぶ理由ができる。
4. **今日の月道**：ソルバーがあるので、生成したコースの安全確認を自動化できる。

物理とレベルの検証は Codex、描画と UI は Claude という Issue #15 の分担を続ける場合は、1 の足場の種類とソルバーを Codex、見た目を Claude に分けられる。
