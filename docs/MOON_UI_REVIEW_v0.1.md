# Moon Lab UIレビュー v0.1

設計方針：**不要なセカンダリラベルや説明を避ける。レイアウトに説明させる。**

## 変更前の試遊問題（ユーザー実機スクリーンショット）
- 画面上部に「HOPSCROLL / MOON LAB」「速度で、道をつくる。」「003 月光橋」「しずかな月光橋」と何重にも見出しがある。
- HOP、月印、SLOWで橋が光る、SLOW ONLY、NEXT、画面外の補足文、画面下のHOLD説明が同時に主張する。
- 失敗カードが足場・着地位置を覆い、直後に何を直せばよいか視覚的に見られない。
- 画面下の説明と二重のボタン類が、遊びのための空間を圧迫する。

## 採用した情報の優先順位
1. **盤面**：キャラ、着地リング、通常床・月光橋、穴、ゴール。
2. **主入力**：大きなHOLDボタンひとつ。リリースでSLOW。キー・タッチ操作は同じ。
3. **局所フィードバック**：失敗地点の赤リング、短い原因、月印からの再試行。
4. **補助**：月印／団子は取得後のみHUDへ。ヘルプ／音／一時停止は小ボタン。

## 具体的な差分
- 大見出し削除、2ステージの小さなタブ化。操作／音ボタンを上部にまとめる。
- HUDは盤面の上に重ね、HOP以外の未取得情報を隠す。月印／団子は獲得した時だけ表示。
- SLOW ONLY連発を排し、橋は実体化・点線で表現。FASTで見える最初の橋にだけ「離して着地」。
- レベル名のCanvas重複描画を止める。
- 開始／中断／結果を盤面上部の小カードにし、水平レーンと着地情報を覆わない。
- 失敗カードは「橋が消えた！」「飛び越した！」等を主体にし、修正ヒントを一行へ。
- #hintは常時表示せず、スクリーンリーダー向けライブ領域として維持。#demoは導入時の触れる見本として維持。
- #resumeは月印復帰時だけ出す。「SLOWで再開」。
- スコア／物理／月印判定／音声判定に変更なし。

## 受け入れ（CIと人間）
- [ ] GitHub Actionsの3画面サイズ (320×700 / 360×640 / 720×1280) でHOLDが表示範囲内。
- [ ] Introと失敗カードは画面下のレーンを覆わない。テストで上部への収まりをチェック。
- [ ] Chromeで初回開始、FAST↔SLOW、橋失敗、月印復帰、二股、ゴールの操作に回帰なし。
- [ ] Androidで画面押下・ボタン押下・復帰後の操作固着なし。
- [ ] キャラの顔・耳・団子が小画面でも読める。**ミチルは別ブランチのため、このUI PRには未統合**。
- [ ] 初見のプレイヤーが文字を読み続けず、橋の見た目と着地リングだけで速度条件に気づくか。

## 注意
表示面積を節約するために必要な情報まで消してはいけない。初見プレイヤーが橋を理解できなかった場合、説明文の常時追加ではなく**最初の橋の短いインタラクティブな見本**を優先する。

## v0.3 星空と触り心地の復活（Issue #15）
- 描画：`src/moon-sky.mjs` を新設し、PR #7 の星空（3層パララックス・星のまたたき・FASTで流れる星・流れ星・星雲）、マントの星くず、ミチルの後ろの彗星の尾を移植した。`flow` は上がるのが速く下がるのが遅いので、RELEASE 後に尾と星の流れがゆっくりほどける。
- 通常の足場は青白く光る道。明るい線は安全範囲（両端から8）にだけ引く。下の光は短く、夜空に溶ける。
- 月光橋は SLOW では薄藤色に光って固く見え、FAST では点線の幽霊になる（`input.fast` に即応）。
- 予測リングは影・塗り・線・短い柱で描き、どの演出よりも上に置く。
- 盤面は横幅360の論理座標を保ったまま、画面に合わせて縦に伸びる。DPR に合わせて描画する。
- 操作：盤面のどこでも長押しで FAST になる。大きな HOLD バーは廃止し、盤面右下の小さな表示（兼ボタン）に置き換えた。初回だけ「画面を押す → FAST / 離す → SLOW」を出し、一度押したら消える（localStorage に記録）。プレイ中に月道の点を押すと、ステージは切り替わらず一時停止する。
- 音：BGM（Love it Rabbit）はローパスで SLOW／FAST／メニューを切り替える。ビルドは `assets/bgm/love-it-rabbit.mp3` があるときだけ同梱し、`<body data-bgm>` で読み込む。速度切替の風切り音と失敗音（`miss`）を追加し、全体音量を .32 → .9 に上げた。着地音のレシピは変えていない。
- 比較：`tests/moon-journey-captures.mjs`（`docs/moon-journey-screenshots/compare/board.png`）。

## v0.4 タイトル・日英切替・練習・団子・月の門
- 月光橋の猶予：FAST を押してから **0.12秒未満**は橋を踏める。0.12秒に達すると橋は消える（浮動小数点許容値を除く）。予測リング、当たり判定、橋の見た目は、どれも同じ規則に従う（`src/moon-core.mjs`）。
- タイトル画面：起動時に表示する。HOPSCROLL のロゴ、ミチル、地球、START（まだクリアしていない最初のステージから始める）、STAGE SELECT、言語、音。カードの ⌂ でタイトルへ戻れ、全ステージをクリアしたあとも戻る。
- 日英切替：`src/moon-i18n.mjs`。初期値は端末の言語で、選んだ言語は localStorage に保存する。Moon Lab は日本語のまま。
- Stage 001 の練習：最初の平らな道で「長押ししてみよう → 指を離すと、ゆっくりに → いいね！」と進む。一度終えると保存され、次からは出ない。
- 団子：予測リングが団子の島に重なると金色になる。取ると「+団子」の表示と金の輪が出て、月道バーの点に桃色の印が付く。団子の島があるステージの結果カードには、取ったか見逃したかを表示する。フィナーレでは届けた数を数える。
- 視点：FAST のときは視点を少し引き（最大 14%）、ミチルを左へ寄せて、FAST の着地点の先まで見えるようにした。
- カード：開始・中断・結果のカードを、道の下（親指の届く場所）に移した。テストも「レーンと跳ぶ範囲に重ならない」ことを確かめる形に変えた。
- ゴール：月の門。柱、アーチ、満月、旗、金の着地パッド、光の柱を描く。クリアすると金の星くずが舞う。

## v0.5 試遊フィードバック対応と流星の海
- タイトルで古いミチルが一瞬映る問題を修正した。スプライトの読み込み中は何も描かない。コードで描く代わりのミチルは、読み込みに失敗したときだけ使う。
- 練習の文言を「押している間はステージが速く進み、遠くに着地する」に直した。
- FAST で視点が伸び縮みしないようにした（酔い対策）。速さは星の流れと尾だけで伝える。
- BGM：FAST で音量が上がらないようにした。音の明るさだけを変え、音量は SLOW .38 → FAST .30 で、聞こえる大きさをそろえた。
- FAST ボタンを戻した：道の下の中央に、うさぎアイコン付きの丸いボタン（92px）。盤面のどこを押しても FAST になる操作もそのまま。
- 流星橋（`kind:'meteor'`）：FAST のまま着地したときだけ固い。離して **0.12秒未満**の着地なら、まだ踏める（月光橋の猶予の逆）。見た目は、FAST で金白の光る帯、SLOW で点線。専用の着地音（`meteor`）と、失敗理由（`meteor-bridge-slow`）を追加した。
- Stage 006「流星の海」：地球見の夜の前に置いた。全23ホップで、お手本のルートから着地点を計算して足場を置いている。お手本のどれか1回の速さを変えると必ず落ちることを、単体テストで確かめている。月印は9ホップ目、開始前に流星橋のデモがある。ソルバーは押す長さを4種類使った20ホップの別解を見つける。
