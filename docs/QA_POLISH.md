# QA · claude/polish-mobile (Issue #2)

## 変更点
- 360×640の論理フレームを丸ごと拡大縮小（`--fit`）。720×1280でもUIが小さくならず、Canvasは端末DPR（最大3）で描画するのでぼけない。
- ウサギ約34%縮小（0.68→0.45）、左寄せ（x=52）、世界の縮尺0.82→0.74で先の見通しを拡大。HOPリングはHUD下へ移動。
- 着地予測：残りジャンプの点線軌道＋着地リング。押す/離すで即座に再計算。色と表示：緑NEXT／赤MISS!（×印）／金GOAL!。もう一方の速度での着地点を薄いリングで表示。
- ゴール：チェック柄の着地パッド、柱、チェック柄バナー、旗、下向き矢印「LAND HERE」。
- 星：放射状の光と白い芯、脈動。取得時にリング・火花・「+★」・2音のチャイム。月は淡色化し、金色は星とゴール専用に。
- Stage 1チュートリアル：切替えると着地が良くなるときだけボタンが脈動し「▼ HOLD NOW!」「LET GO!」を表示。他ステージも3回失敗すると同じ補助が出る。
- 入力：ボタンに加えて画面（Canvas）押下でもFAST。指・キーごとに追跡（マルチタッチで固着しない）。pointercancel／lostpointercapture／blur／visibilitychange／pagehide／リトライで解除。長押しメニュー抑止。アプリ切替で一時停止しRESUME。
- 演出：FAST切替の風切り音、離陸・着地のスカッシュ、FAST時の前傾と流線、着地の砂ぼこり、クリア時の紙吹雪と喜び顔、落下アニメ後に結果表示。
- ミュートボタン（M キー）、モーダルはSpace/Enterで操作可能。`prefers-reduced-motion`で揺れ・粒子・フラッシュを停止。

## 2026-10-30 Codex core #3 統合後の失敗理由 UI 連携
- `onFail()` は `state.failure` を参照し、ゴール通り越し・足場の縁・足場間の穴・プラットフォーム手前/通り過ぎを区別する。
- `failure.correction` は「最近傍の安全な足場へ寄せる方向」であり「ステージ正解への誘導」ではないため、UIに断定的な FAST/SLOW 助言は出さない。
- `state.failure` が無い場合も従来の一般的なリトライ説明へフォールバック。
- ブラウザ実操作とAndroid実機で、失敗位置と案内文が一致するか確認する（以下はまだ未検証）。

## v0.3 星うさぎ＆流星レーン（claude/star-rabbit-visual）
ビジュアルと音の改修のみ。`src/core.mjs`・`tests/*`・ステージ配置・物理定数（0.78秒／105／270px/s）は変更していない。

### 変更点
- **星うさぎ**：Canvasで描く横向きシルエット（クリーム色の体、長い耳、星形のしっぽ、縁の淡い発光）。大きさは旧うさぎとほぼ同じ（約52px）。
  - ジャンプ中は縦に伸び、着地直後はばねの動きで「ぷにっ」と縮む。
  - 耳はばねで動く。FASTでは後ろへなびき、SLOWではふわっと戻る。上昇中も少し後ろへなびく。
  - FASTでは前傾する。クリア時は笑顔で小さく跳ね、失敗時は目が×になる。
- **夜空**：紺から青紫、地平線の淡い水色へのグラデーション。星雲、淡い月、3層のパララックス星を配置。FASTでは星が光の筋に伸び、流れ星が流れる。SLOWでは星がまたたく。
- **流星レーン**：足場は青白く光る帯。上面の白い線は当たり判定の安全区間（両端8px内側、`isSafe`と同じ）にだけ引いている。足場の下は光が落ち、穴は暗い虚空になる。レーン上の流れる線はFASTで長い筋になる。
- **流星の尾**：うさぎの実際の軌跡に沿う彗星の尾（FASTで長く明るい）と、しっぽから散る星くず（SLOWでは少し出てすぐ消え、FASTでは長く流れる）。
- **切替の瞬間**：FASTで星くずのリングがはじけ、SLOWでふわっと散る。画面揺れは使わない。
- **星アイテム**：光る五芒星。取得時に星くずが飛び散り、2音のベル風チャイムが鳴る。
- **ゴール**：金色のスターゲート。柱とアーチ、大きな星の冠、金色の着地パッド、「GOAL」「LAND HERE」と下向き矢印を描く。着地成功で星くずが舞い上がる。Stage 1の練習用フィニッシュラインも星付きの柱に変更。
- 着地予測の緑NEXT／赤MISS!／金GOAL!は変更なし。
- **BGM**：「Love it Rabbit」（えだまめ88／OpenTracks）。ローパスフィルタを通し、SLOWはこもった柔らかい音、FASTは全帯域の明るい音、カード表示中はさらに奥に下げる。ミュートで停止、アプリ切替で停止し、再開ボタンで戻る。
- **UI**：HUD・ボタン・カードを夜空の配色に変更。カードはポップインで出る。タイトルとポーズのカードは生成キーアート、結果カードはCanvasうさぎ（表情つき）。
- reduced-motion：星の筋・流れ星・星くず・耳のばね・伸び縮み・フラッシュを止める。
