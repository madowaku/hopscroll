# 月兎娘キャラクター設定 v0.1（HOPSCROLL）

> **仮名：ミチル / MICHIRU**。ユーザー承認前の仮決定であり、改名容易にすること。
> 企画の核：**「月には月見がない。月の住人たちは、地球を眺めながら団子を食べる。」**

## 一文のキャラクター像
月の裏側に住む兎人の女の子。今夜は「地球見」のお祭り。三色の月見団子を落とさないよう、止められない跳躍に身を任せて星の道を渡る。おっとりしているが、団子だけは絶対に手放さない。

**人間のような女の子＋兎耳**。普通の四足歩行ウサギではない。世界観の説明は長い文章よりタイトルの一枚絵とクリアの小さな表情で伝える。

## 見た目：固有の4要素（縮小しても残す）
1. **耳が左右非対称**：右耳は長く立ち、左耳の先だけ少し曲がる。FASTでは両耳が後方になびく。
2. **淡い白銀色の短い髪と頬**：眼は焦げ茶の大きな二点、口は小さい。表情は穏やか、成功した時だけ歯を見せずに笑う。
3. **三日月の裾をもつ、ふわりとした衣**：月白～薄藤色の短い外套（広い袖・裾が風を受ける）、内側は紺。腰に細い金色の帯。速度で生地のシルエットが変わる。
4. **団子**：三つ連なった月見団子を片手で持つ。小画面では「棒＋白い丸3つ」に省略。タイトル絵では盆に載った三色団子を片手で支えてもよい。操作で団子を落とす・失うというペナルティは**実装しない**。

## デザインと配色
- 顔・肌：薄桃～アイボリー、耳裏：薄桜、髪：月白。
- 衣：薄藤 #BFB7E8 と白 #F4F0E7、影：濃紺 #243052。
- 星・三日月のアクセント：金 #FFD879（ゴールやアイテムに使う色なので面積は小さく）。
- 団子：白2個＋薄桃1個（小さい画面では白3点）。
- 人物の輪郭に夜空と分離する淡い青白い縁光。エフェクトが足場判定を覆わないこと。

## 3つの表情とモーション
| 状況 | キャラクター | ゲーム情報 |
|---|---|---|
| SLOW | 袖と裾がふわっと広がり、左耳が垂れる。団子を大切に抱く | スピードを落としたと伝わる |
| FAST | 袖・耳・帯が後ろへ一直線、体は小さく前傾。団子をかばう | 加速が見た目だけでも分かる |
| 着地／失敗 | ぷにっと膝を曲げて小さな星の粒が弾む。失敗時は団子だけ空中で一瞬浮く（任意） | 成功・失敗をすぐ識別 |

ジャンプ周期0.78秒は変えない。現行の約52pxのウサギと衝突判定・表示位置を維持しつつ、**ゲーム中は55～64px相当の2.5～3頭身の月兎娘**とする。大きさが着地視認性を損なう場合は元サイズへ戻す。タイトル絵・クリアカードでは等身を少し上げてもよい。タイトル／プレイ中／結果画面で同じ耳・服・団子のシルエットを保つ。

## 物語の見せ方（最小限）
- タイトル：月の裏側から地球を望む。ミチルが団子の串を握り直す。短い一文「地球がいちばんきれいな夜。」
- ステージ1：月の庭から流星の道へ。失敗しない安全地帯から始める。
- 中盤：雲・月光橋・二股の道。台詞で説明せず、絵と動きで理解させる。
- 最終：大きな地球が見える「地球見祭」に到着。団子を差し出した瞬間に小さく息をつく。
- ジャム用の完成演出は2～4秒の静かな1枚＋「THE END / THANK YOU」。スキップ可能。

## ゲーム上の役割
操作は人を走らせることではなく、**彼女の足下を流れる星の道の速さを調節する**こと。身体は自動で跳び続ける。動作の理由がキャラクターと一致していることが大切。

団子をギミックとして消費・落下させない。代わりにステージ4の分岐で「おまけ団子」を任意取得する設計に使う。緊張の核は速度と着地だけに残す。

## アート制作・受入条件
- まず**正面／横向き／SLOW／FAST／着地**の静止小ラフを作る。参考絵とCanvas版の一致を確認。
- 48pxでも「兎人・片方だけ折れた耳・ふわり袖・団子」が読み取れるかテスト。
- 生成画像をタイトル／カバーへ使う場合はプロンプト・制作経緯を記録し、itch.ioのAI利用開示を確認。
- クロ姉はビジュアル担当。Codexは物理・コース・ソルバー担当。キャラクター変更のために物理変更はしない。
